# 统一领域语言

## 执行步骤
1. 梳理对话，筛选领域相关名词、动词与业务概念
2. 识别用语问题：语义歧义 / 用语不统一 / 一词多义
3. 敲定标准词汇，形成术语清单
4. 将清单写入文件 `service-map.md`, 已存在则整理后追加（格式如下）
5. 在对话中输出总结

## 输出格式
```md
# 统一领域语言

## [业务板块]

| 标准术语 | 释义 | 禁用同义叫法 |
|---|---|---|
| **术语** | 业务含义 | 禁用词 |

## [业务板块]
...

## 业务关联关系
- 实体A → 实体B 对应规则

## 歧义标注
- 词汇A 同时指代 X 和 Y → 明确区分边界
```

## 规则
- 同一概念唯一标准名称，同义表述列禁用
- 仅收录业务领域词汇，不收录编程通用概念
- 释义一句话说明本质
- 按业务板块分组，标注实体关联关系
- 标注语义冲突并给出使用建议

## 重复调用
1. 读取已有文档
2. 吸纳新增词汇
3. 修正释义
4. 标注新歧义
